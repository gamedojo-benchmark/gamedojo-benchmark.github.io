# Model icons

- GPT, Claude, Gemini, DeepSeek, GLM, MiniMax, and Qwen use [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons). The OpenAI mark is shown in white on a teal tile. See [LICENSE.txt](LICENSE.txt).
- GameScaling uses its [project favicon](https://gamescaling.github.io/assets/favicon.svg).
- Gamer uses a small vector adaptation of the [project mascot](https://mihoyo-gamer.github.io/assets/gamer-logo.svg).
- GameDojo uses the same illustrated G as the [site favicon](../../img/favicon.png), encoded as SVG paths from the original RGBA pixels.

Brand marks belong to their respective owners.
